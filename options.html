Canvas to Calendar

Put your Canvas assignments on your calendar.

👋 You're all set to start

  1. Open your school's Canvas site and log in.
  2. Click the Canvas to Calendar icon in your toolbar. Pin it from the puzzle-piece menu so it's easy to find.
  3. Tick the assignments you want, then click .ics or the + next to an assignment. Both work right away.

For one-click syncing that also keeps due dates up to date, connect Google Calendar below.

Google Calendar connection

Only the Add to Google Calendar button needs this. Google requires every app that writes to your calendar to have its own login key ("Client ID"), which you create for free in Google Cloud.

Step-by-step setup (about 5 minutes)
  1. Open Google Cloud Console and create a project (any name).
  2. Turn on the Google Calendar API for that project.
  3. Open Google Auth Platform and click Get started. Enter any app name and your email, and choose External.
  4. Under Audience → Test users, add every Gmail address you'll sign in with.
  5. Under Clients → Create client, choose Web application. Under Authorized redirect URIs, add this exact address:
  6. Click Create and paste the Client ID below. Don't paste the client secret.

Changes in Google Cloud can take a few minutes to start working. When you first sign in, Google warns that the app "isn't verified". That's expected for an app you set up yourself, so click Continue.
